# Spellblade portrait icons

The browser favicon, Apple touch icon and installed app use the existing `docs/release/media/spellblade-avatar-art.png` portrait. CaptainFredric created the original character design; the portrait is its previously approved AI assisted promotional refinement. The source image is unchanged.

The PNGs are Lanczos resamples at 32, 180, 192 and 512 pixels. The maskable 512 icon places a 360 pixel portrait on a crimson field, protecting the helmet, crest and visor within the central mask area. New filenames avoid stale caches of the previous crest icon. Legacy icon assets remain available but are unused by the page and app manifest.
